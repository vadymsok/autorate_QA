# Протокол ретроспективи Спринту 2

* **Дата проведення:** 15.10.2026
* **Учасники:** Литвиненко Артем (KT), Соколов Вадим (TA), Томашук Дмитро (IT), Тарасюк Арсен (SM)
* **Фасилітатор:** Тарасюк Арсен (Скрам-майстер)
* **Формат:** Start / Stop / Continue

---

## 1. Start (Почати робити)
* Одразу перевіряти технологічний стек і архітектуру на відповідність вимогам кафедри перед початком аудиту.
* Завчасно вести та фіксувати аркуш «Спірні» під час аудиту вимог для колегіального вирішення розбіжностей.
* Синхронізувати точну кількість дефектів у таск-борді (`tasks.md`) із підсумковим реєстром (`requirements-defects.xlsx`).

---

## 2. Stop (Припинити робити)
* Припинити вносити правки з шаблонними мітками ШІ в описах дефектів та формулюваннях SRS 1.1.
* Припинити зведення єдиного реєстру дефектів без попередньої фіксації та обговорення пунктів на аркуші «Спірні».
* Не допускати технічних помилок при завантаженні файлів (дублювання розширення `.xlsx.xlsx` у репозиторії).

---

## 3. Continue (Продовжувати робити)
* Продовжувати практику парного незалежного аудиту розділів специфікації (перевірка кожного розділу двома учасниками).
* Зберігати перехресне рецензування артефактів роллю «адвоката замовника».
* Підтримувати актуальний стан дошки задач і дотримуватися структури репозиторію курсу.

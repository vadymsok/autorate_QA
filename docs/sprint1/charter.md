## 2. Методологія, методи та прийоми
* **Методологія:** Полегшений Scrum (Lightweight Scrum), адаптований під навчальний процес. Розробка розділена на 5 двотижневих спринтів із фіксованими артефактами, процедурами ретроспективи, демо та обов'язковою ротацією ролей.

* **Методи:** 
  * Моделювання бізнес-процесів у нотації BPMN 2.0.
  * Декомпозиція вимог замовника через User Stories із чіткими Acceptance Criteria та граничними значеннями.
  * Перехресне внутрішнє рецензування (Cross-Review) за 10-пунктовим чек-листом якості.

* **Прийоми:** 
  * Асинхронні щоденні стендапи в Telegram-чаті та на Discord-сервері;
  * Правило «Одна задача — один виконавець — один рецензент».

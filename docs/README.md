## Середовище та обмеження

Run 1–4 виконувалися на публічному demo. Середовище останнього прогону: Chrome/CDP, desktop viewport 1363 CSS px, 17.11.2026. У попередніх прогонах частина перевірок здійснювалася в підготовленій спільній сесії, тому ці виконання не підміняють незалежного повторення кожного кейсу. Дані публічного каталогу динамічні.

Із 14 Blocked дев'ять вимагають конкретних тестових наборів для авторизації/реєстрації, два — іншого доступного браузерного або мережевого режиму, три — уточнення критерію очікуваного результату. Технічна перевірка документів підготовлена; незалежне рецензування студентами та проведення ретроспективи в цьому зрізі не підтверджені.

**Висновок:** нормативи за кількістю кейсів, дефектів і рівнів Severity досягнуті. Невиконані пункти DoD перелічено в [чек-листі](DoD-checklist.md); статус завершення не перебільшено.

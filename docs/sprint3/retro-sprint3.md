## 1. Підсумки спринту
* Спроєктовано та виконано тест-кейсів: 20 (норматив виконано).
* Статуси прогону: Passed — 12, Failed — 8, Blocked — 0.
* Знайдено дефектів на demo: 8.
* 100% тест-кейсів та звітів про дефекти пройшли внутрішнє рецензування.

## 2. Аналіз у форматі Start / Stop / Continue

### Start
* Заздалегідь готувати граничні тестові значення у вигляді окремої шпаргалки до відкриття форми на сайті.
* Фіксувати точну дату стану demo та версію браузера в першому рядку сесії тестування.

### Stop
* Припинити вказувати абстрактні очікувані результати типу "працює коректно" (лише конкретні написи, коди, кнопки).
* Припинити створювати звіти про дефекти без обґрунтування полів Severity та Priority.

### Continue
* Практику перехресного рецензування артефактів Скрам-майстром перед комітом у main.
* Фіксацію наочних скріншотів із виділенням проблеми для кожного дефекту.

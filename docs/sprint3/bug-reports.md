# Реєстр дефектів (Спринт 3)

## BUG-001
**Title:** Авторизація: Замість повідомлення про невірний пароль виникає помилка сервера 500 (F-10)
**Severity:** Critical | **Priority:** P2
**Linked:** TC-002; F-10
**Description:** При спробі входу з неправильним паролем система не обробляє виключення і падає з HTTP 500, замість виведення червоного тексту помилки. Це критично погіршує користувацький досвід під час авторизації.
**Steps to reproduce:**
1. Відкрити `https://autorate-demo.com/login`.
2. У поле Email ввести `user@autorate.com`, у поле Password ввести `wrongpass123`.
3. Натиснути кнопку «Увійти».
**Actual result:** Сторінка біліє, у консолі та Network відображається `500 Internal Server Error`. Повідомлення про невірний пароль відсутнє.
**Expected result:** Вхід не виконано (URL `/login`). Відображається червоне повідомлення: «Невірний email або пароль».
**Environment:** demo 25.10.2026; Chrome 129.0; Windows 11; без входу.
**Attachments:** `BUG-001.png` (скріншот 500 помилки в консолі).

## BUG-003
**Title:** Вибране: Доданий автомобіль не зберігається у списку «Вибране» в профілі (F-40)
**Severity:** Major | **Priority:** P2
**Linked:** TC-006; F-40
**Description:** Користувач отримує сповіщення про успішне додавання авто, проте дані не зберігаються в базу, і розділ залишається порожнім. Основний функціонал "Мій профіль" порушено.
**Steps to reproduce:**
1. Авторизуватися та відкрити картку авто `https://autorate-demo.com/cars/tesla-model-3`.
2. Натиснути кнопку «Додати у вибране» (іконка серця).
3. Перейти у «Мій профіль» -> «Вибране».
**Actual result:** Іконка змінює колір, з'являється сповіщення про додавання, але розділ «Вибране» у профілі абсолютно порожній.
**Expected result:** У розділі «Вибране» міститься 1 збережена картка — Tesla Model 3.
**Environment:** demo 25.10.2026; Chrome 129.0; Windows 11; user: `vadym_qa`.

## BUG-004
**Title:** Відгуки: Система приймає та публікує оцінку 0 зірок (F-50)
**Severity:** Critical | **Priority:** P1
**Linked:** TC-008; F-50
**Description:** Допускається збереження оцінки, нижчої за мінімальний поріг (1 зірка). Оскільки 0 зірок бере участь в агрегації, це безповоротно ламає підсумковий рейтинг моделі. Блокує подальше тестування рейтингів.
**Steps to reproduce:**
1. Авторизуватися та відкрити `https://autorate-demo.com/cars/toyota-camry`.
2. Через DevTools (або API) у полі вибору оцінки ввести значення `0`.
3. Натиснути кнопку «Опублікувати відгук».
**Actual result:** Відгук із 0 зірок успішно зберігається і відображається в картці автомобіля.
**Expected result:** Публікація блокується. Повідомлення: «Мінімальна оцінка становить 1 зірку».
**Environment:** demo 25.10.2026; Chrome 129.0; Windows 11; user: `vadym_qa`.
**Attachments:** `BUG-004.png` (скріншот опублікованого відгуку на 0 зірок).

# Реєстр дефектів (Спринт 3)

## BUG-001
**Title:** Авторизація: Повідомлення про помилку входу має помаранчевий колір замість червоного
**Severity:** Trivial | **Priority:** P3
**Linked:** TC-002; GUI-30
**Description:** Згідно із загальними UI/UX стандартами, повідомлення про помилку валідації або невірні дані мають відображатися червоним кольором (Error). Наразі бедж `Invalid username/password` має помаранчевий колір (Warning), що є косметичним недоліком і може дезорієнтувати користувача.
**Steps to reproduce:**
1. Відкрити `https://buggy.justtestit.org/` (нова сесія).
2. У поле Login у верхній панелі ввести `blablaqwerty123blabla`.
3. У поле Password ввести випадкові символи.
4. Натиснути кнопку «Login».
**Actual result:** Поруч із формою з'являється помаранчевий бедж із білим текстом `Invalid username/password`.
**Expected result:** Повідомлення про невірні облікові дані відображається на червоному тлі, щоб чітко сигналізувати про помилку.
**Environment:** demo 25.10.2026; Chrome 129.0; Windows 11; без входу.
